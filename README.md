# DevPulse – Cloud Infrastructure Landing Page

## Overview

DevPulse is a responsive cloud infrastructure landing page designed to showcase scalable infrastructure services, monitoring tools, and cluster hosting plans.

The website allows users to explore platform features, compare pricing tiers, estimate workload requirements, and register for API sandbox access.

## Features

- **Hero Section:** Introduces DevPulse with a clear value proposition and prominent deployment call-to-action.
- **Infrastructure Features:** Showcases latency tracking, log aggregation, and automated remediation.
- **Pricing Tiers:** Compares Developer, Pro Cluster, and Enterprise Dedicated plans, including a most popular tier indicator.
- **Workload Estimator:** Provides numeric inputs for node count and log throughput with minimum and maximum constraints.
- **Registration Form:** Collects user information for API sandbox registration.
- **Responsive Layout:** Uses CSS Grid, flexible layouts, and styling designed for different screen sizes.
- **Navigation:** Includes section links for Features, Pricing, and Registration.

## Technologies Used

- HTML5 – Page structure and semantic elements
- CSS3 – Styling, layouts, hover effects, and responsive design
